# わたしの本棚

## コンポーネント

- `App`: 本のデータを管理し、一覧を表示します。
- `BookCard`: 1冊分のタイトル、著者、評価、コメントを表示します。

## BookCardに渡すprops

- `title`: 文字列。書名です。
- `author`: 文字列。著者名です。
- `rating`: 数値。評価です。
- `comment`: 文字列。本の感想です。

## key

`map`で各本を表示するとき、`key`には本ごとに異なる`id`を使いました。`id`は一意で安定しているため、Reactがリスト内の項目を正しく識別できます。

## 詰まったところ

`map`で表示する項目に`key`が必要だと分からず、各本に`id`を用意して`key={book.id}`を指定しました。
